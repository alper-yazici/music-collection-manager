# Music Collection Manager

A Python application for managing a personal music collection.

## Current Features

- Manage a personal music collection using Python
- Support for physical and digital music media
- Represent vinyl records with specific attributes
- Add music items to a collection
- Display all items in the collection
- Search for music by artist or album
- Case-insensitive search functionality
- Automated unit tests for collection search methods

## Technologies

- Python 3.12
- Object-Oriented Programming (OOP)
- Python unittest framework
- Git & GitHub

## Installation & Usage

### 1. Clone the repository:

```bash
git clone https://github.com/alper-yazici/music-collection-manager.git
```

### 2. Navigate to the project directory:

```bash
cd music-collection-manager
```

### 3. Run the application:

```bash
python main.py
```

## Running Tests

This project uses Python's built-in unittest framework
to test the music collection's search functionality.

To run all tests, execute:

```bash
python -m unittest discover -s tests -v
```

To current test suite covers:
- Searching for music items by artist
- Searching for music items by album
- Case-insensitive artist and album searches
- Handling searches wit no matching results
